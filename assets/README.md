# WideMelon branding assets

The WideMelon logo and its rendered icon sizes are project-specific branding
introduced in 2026. They are not Nintendo, Pokémon, game, or melonDS artwork.
`res/widemelon.ico` contains the rendered 16, 32, 48, 64, 128, and 256 pixel
PNG variants for the Windows executable resource.

To the extent copyright subsists in these assets, WideMelon contributors make
them available under GPL-3.0-or-later with the rest of the application.
